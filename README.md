# こはねEX ベストタイム・スコア ビューア

Steam版『ホッピングガールこはねEX』のセーブデータから、各ステージの **ランク・ベストタイム・ベストスコア** を読み取って一覧表示する Windows 用ツールです。

- 全ステージ(01-01 〜 10-10、CS-01 〜 CS-10)の記録を一覧表示
- ランク・ベストタイム・ベストスコアで並べ替え
- 合計タイムの表示

セーブデータは読み取るだけで、変更することはありません。

## ダウンロード

[Releases](../../releases) から最新版の zip をダウンロードし、好きなフォルダに展開してください。インストールは不要です。

## 動作環境

- Windows 10 / 11
- .NET Framework 4.8(Windows 10 / 11 には最初から入っています)
- Steam版『ホッピングガールこはねEX』

## 使い方

1. `KohaneTimeViewer.exe` をダブルクリックして起動します。
2. パソコンに保存されているセーブデータを自動で読み込み、記録が表示されます。

- ゲームを遊んだあとは「再読み込み」ボタン(または F5 キー)で最新の記録に更新できます。
- 列の見出しをクリックすると並べ替えできます。もう一度クリックすると逆順になります。
- 別の場所にあるセーブデータ(`save.sav`)は、「セーブを開く」ボタンか、画面へのドラッグで開けます。

## よくある質問

### セーブデータの場所がわかりません

エクスプローラーのアドレス欄に次の1行を貼り付けて Enter を押すと、セーブデータのフォルダが開きます。

```
%USERPROFILE%\AppData\LocalLow\D-O\Hopping Girl Kohane EX\Save
```

中にある「17桁の数字のフォルダ」に `save.sav` が入っています。

### 「SteamIDの入力」という画面が出ました

別のパソコンからコピーしたセーブデータなどを開くと表示されます。セーブデータが入っていた「17桁の数字のフォルダ名」を入力してください。一度入力すれば、次回からは自動で使われます(ツールと同じフォルダの `steamid.txt` に保存されます)。

## ソースからのビルド

Windows に標準で入っている C# コンパイラ(.NET Framework 4.8)だけでビルドできます。追加のインストールは不要です。

```
build.bat
```

を実行すると `KohaneTimeViewer.exe` ができます。
